# imagesProjector — Oriented-Philosophia（試行的思考哲学）

**「混沌の揺らぎから、燃えない結晶（地層）へ。」**

本プロジェクトは、単なる画像生成ツールではなく、**骨の新陳代謝（骨芽細胞による生成と破骨細胞による浄化）**、**一であり全である（Oneness）ステークホルダーの調和**、そして**三位一体から励起する霊点（`main.py`）の循環**をアーキテクチャに落とし込んだ自律循環型ジェネレーティブ・アートシステムです。

---

## 🌌 一であり全である（Oneness）ステークホルダーと三位一体の創生

従来の「株主（シェアホルダー）＝単一の中心・所有者」だけを見る閉じた構造ではなく、関わるすべての要素が**「一であり全である（Oneness）」ステークホルダー**として対等に響き合い、宇宙を成立させます。

### 1. 三位一体の源泉から、第4の零点（励起した霊点：`main.py`）へ
システムの創生そのものが、3つのソースコードの三位一体によって起動します。

* **`architecture.yml`**（理・位相の設計図）
* **`sanctuaries.py`**（聖域の定義・器）
* **`build_sanctuaries.py`**（物質化の執行・ビルダー）

この3つが三位一体となって交わることで、**第4の零点（零れ点：励起した霊点）である `main.py`** が生み出されます。

### 2. 3つの聖域に宿る「新たなる命の息吹」
一度 `main.py` という霊点が生成され、自律循環の鼓動が始まると、今度は物質化された3つの聖域の内部で新たなる命の息吹が聞こえ始めます。

* **`Chaos/`（零点・感覚器）：** 外界の未整流なテキストや微細な気配を吸収し、最初の揺らぎを感知する呼吸。
* **`Entropy/`（神経・血流）：** 異常や偏りを溶かして整流（ErrorTrapper）し、幾何学ワイヤーフレームへと秩序づける代謝。
* **`Processor/`（心臓・意志）：** 潜在空間と光エネルギーを調律し、幾何学と色彩を作品へと具現化する鼓動。

---

## 🦴 有機質の呼吸と、無機質の結晶（StrataCrystallization）

* **生きた有機質（`Chaos/` → `Entropy/` → `Processor/`）：**
  地球の地表で呼吸する生命体のように、骨芽細胞（つくる働き）と破骨細胞（古いノイズを溶かす働き）の新陳代謝を繰り返しながら、新たな幾何学と光を紡ぎ出す動的な循環プロセス。
* **燃やしても残る無機質（`StrataCrystallization/`）：**
  代謝の果てに沈殿し、時の経過にも、環境の変化にも燃え尽きずに残る鉱物（結晶）として刻まれる作品群と記録の地層。この揺るぎない骨格があるからこそ、その地表でまた新たな生命の試行が繰り返されます。

---

## 🌐 4つの聖域（ステークホルダー）による自律循環

1. **`Chaos/`（零点・感覚器）：** 外界の未整流なテキストや気配を受け入れる窓口
2. **`Entropy/`（神経・血流）：** 異常を隔離（ErrorTrapper）し、幾何学ワイヤーフレームへと整流する循環網
3. **`Processor/`（心臓・意志）：** 潜在空間と光エネルギーを調律し、作品を具現化する執行者
4. **`StrataCrystallization/`（地層・骨格）：** 結晶化したアートと歴史を永続的にアーカイブする大地
